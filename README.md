# Android Application

## About the Project

This Android application was developed as part of my learning and practice in Android development. The main objective of this project is to understand Android application structure, UI design, activity navigation, and project organization using Android Studio.

The application has been developed, tested, and executed manually on an Android emulator and a physical Android device.

## APK

The generated APK is available in the following directory after building the project:

```
app/build/outputs/apk/debug/app-debug.apk
```

You can install the APK on any Android device by enabling **Install from Unknown Sources** if required.

## How to Run

1. Download or clone this repository.
2. Open the project in Android Studio.
3. Wait until Gradle finishes syncing.
4. Connect an Android device or start an emulator.
5. Click the **Run** button.
6. The application will be installed automatically.

---

## Build APK

To generate the APK:

1. Open Android Studio.
2. Select **Build** → **Build APK(s)**.
3. Wait for the build process to complete.
4. The APK will be created inside:

```
app/build/outputs/apk/debug/
```
